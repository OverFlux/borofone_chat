# Borotalk v0.2.0 — VPS, закрытый доступ и TURN

Этот релиз добавляет полноценный режим размещения Borotalk на собственном VPS
с обычным HTTPS-доменом. Radmin-сценарий и подключение к self-hosted хостам
остаются доступными для обратной совместимости.

## Главное

- единый файл `Borotalk-VPS-Installer.run` для установки на Ubuntu/Debian;
- автоматическая настройка Docker, Nginx, HTTPS, PostgreSQL, Redis, worker и coturn;
- безопасное обновление через `--update` с сохранением базы, uploads и `.env`;
- закрытая регистрация: email-подтверждение, одноразовые инвайты и заявки владельцу;
- одобрение заявок через Telegram с резервной веб-очередью;
- восстановление пароля, ротация refresh-сессий и Redis rate limits;
- приватные серверы, непрогнозируемые публичные ID, серверные инвайты и заявки;
- собственный STUN/TURN с краткоживущими credentials для сложных сетей;
- новый onboarding и понятный пустой экран для пользователя без серверов;
- HTML-письма Borotalk для подтверждения email и восстановления пароля;
- Desktop schema v2 для системно доверенных HTTPS-доменов при сохранении schema v1;
- локальный Windows-стенд `TEST_VPS_LOCAL.bat` с Mailpit для проверки без VPS.

## Что скачать

- `Borotalk-VPS-Installer.run` — установка или обновление сервера;
- `Borotalk.Desktop-0.2.0.Setup.exe` — установщик Desktop для Windows x64;
- `Borotalk.Desktop-win32-x64-0.2.0.zip` — portable-версия Desktop.

Windows-сборка не подписана цифровой подписью, поэтому SmartScreen может
показать предупреждение. Проверяйте имя файла и SHA-256 перед запуском.

## Установка VPS

Полная пошаговая инструкция:
[VPS_INSTALL_RU.md](https://github.com/OverFlux/borofone_chat/blob/main/docs/VPS_INSTALL_RU.md).

Быстрый запуск после настройки DNS, firewall, SMTP и Telegram-бота:

```bash
curl -fL \
  https://github.com/OverFlux/borofone_chat/releases/latest/download/Borotalk-VPS-Installer.run \
  -o /tmp/Borotalk-VPS-Installer.run

sudo bash /tmp/Borotalk-VPS-Installer.run
```

Проверка:

```bash
sudo bash /opt/borotalk/INSTALL_VPS.sh --check
```

Обновление:

```bash
sudo bash /tmp/Borotalk-VPS-Installer.run --update
```
