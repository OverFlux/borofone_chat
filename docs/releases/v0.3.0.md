# Borotalk v0.3.0 — нативный VPS и Resend

В этом выпуске появился изолированный установщик для небольшого Ubuntu/Debian
VPS, где уже работают VPN, Telegram-боты или другие сервисы.

## Главное

- один файл `Borotalk-VPS-Native-Installer.run` для установки без Docker;
- отдельные systemd-unit для API, worker, Redis, Nginx и coturn;
- запуск по публичному IPv4 с доверенным короткоживущим сертификатом и
  последующее переключение на домен;
- асинхронная отправка писем через Resend Python SDK со стабильными
  idempotency keys;
- сохранённый SMTP fallback для прежних self-hosted установок;
- TURN по UDP/TCP 3478, TLS 5349 и дополнительному UDP 443;
- ежедневный проверяемый backup PostgreSQL и uploads с ротацией трёх копий;
- health-check диска, памяти и изолированных сервисов;
- Telegram-интеграцию можно подключить позже, веб-очередь заявок продолжает
  работать без неё.

## Установка

Перед началом сделайте snapshot VPS. Затем скачайте release asset и запустите:

```bash
sudo bash Borotalk-VPS-Native-Installer.run
```

Подробности находятся в [инструкции по нативной установке](../VPS_NATIVE_IP_RU.md).
