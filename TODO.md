# Borotalk — roadmap

Обновлено: 29 июля 2026.

## Выполнено

- [x] Публичный Nova-лендинг на `/`.
- [x] Отдельный запуск приложения через `/main.html`.
- [x] Полностью новый интерфейс без загрузки legacy UI.
- [x] Voice-first компоновка: серверы и каналы слева, голос в центре, чат справа.
- [x] Светлая и дымчато-серая тёмная темы; в тёмной теме зелёный акцент приглушён.
- [x] Карточки участников голосового канала приведены к Nova-макету главной страницы.
- [x] Понятные кнопки голосового управления с иконками, подписями и доступными состояниями.
- [x] Адаптивные панели для desktop, tablet и mobile.
- [x] Навигация с клавиатуры и `prefers-reduced-motion`.
- [x] Реальные серверы, текстовые и голосовые каналы в PostgreSQL.
- [x] Членство и роли внутри сервера.
- [x] Поиск серверов и пользователей по уникальному ID.
- [x] Присоединение к серверу по ID.
- [x] Полное управление сервером: создание, переименование, доступ по ID, выход, передача владельца и удаление.
- [x] Личные диалоги и realtime-доставка личных сообщений.
- [x] Realtime-доставка сообщений текстовых каналов через Redis с локальным fallback.
- [x] Мягкие антиспам-лимиты чата: короткий burst и минутный предел с понятным ожиданием.
- [x] Счётчик длины сообщения и явное состояние лимита `2000 из 2000`.
- [x] Серверная изоляция REST и WebSocket-событий.
- [x] P2P-голос через WebRTC.
- [x] Демонстрация экрана через WebRTC.
- [x] Полноценное окно трансляции: выбор потока, zoom, drag, fit/fill, PiP, fullscreen и сворачивание.
- [x] Ограниченное восстановление WebRTC после смены сети и неудачного ICE-соединения.
- [x] Микрофон, mute, deafen и выход из голосовой комнаты.
- [x] Выбор микрофона и устройства вывода с локальным сохранением.
- [x] Простой чат без интерфейса вложений.
- [x] Встроенный набор кастомных эмодзи.
- [x] Встроенные пресеты аватаров.
- [x] Изменение отображаемого имени и английского никнейма.
- [x] Встроенные звуки подключения и сообщений.
- [x] Локальный demo-вход и demo-сервер `Boro friends`.
- [x] Обновлённый PWA-кэш без legacy-ресурсов.
- [x] Убраны emoji-пиктограммы из системных кнопок, исправлены отступы личных диалогов и лишний скролл voice-stage.
- [x] Системные кнопки переведены на единый SVG-набор без наложений и обрезанных линий.
- [x] Новый favicon/PWA-icon с mint voice-знаком Nova.
- [x] Favicon обновлён до белой скруглённой плитки с прозрачными углами.
- [x] Mute/deafen видны всем участникам: красная обводка mute и красные наушники deafen.
- [x] Stage intro показывает, кто уже находится в выбранном голосовом канале.
- [x] Формы входа настроены для сохранения email и пароля менеджером паролей.
- [x] One-click запуск через Radmin VPN с автоматическими HTTPS, Firewall, инвайтом и папкой для друзей.
- [x] MongoDB не используется.

## Следующие этапы

- [ ] Протестировать голос и демонстрацию экрана между несколькими реальными устройствами через Radmin/VPN.
- [ ] Добавить управление участниками и ролями владельца/модератора.
- [ ] Добавить непрочитанные сообщения для каналов и личных диалогов.
- [ ] Провести нагрузочную проверку WebSocket-подписок и голосовых комнат.
- [ ] Провести финальный аудит зависимостей и физически удалить больше не используемые legacy-файлы.
- [ ] Усилить rate limits, журналирование ошибок и проверку некорректных realtime-событий.
- [ ] Зафиксировать стабильный протокол для будущего Android-клиента.
- [ ] Подготовить отдельный Android-клиент после стабилизации desktop/web-версии.
- [ ] Подготовить staging и production-развёртывание после локального одобрения.
